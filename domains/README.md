# awdev.my.id Subdomain Registry

Layanan pendaftaran subdomain gratis untuk developer menggunakan domain `awdev.my.id`.

## Cara Registrasi
1. Fork repository ini.
2. Buat file baru di dalam folder `domains/` dengan nama subdomain Anda (contoh: `namaanda.json`).
3. Masukkan konfigurasi DNS record (CNAME atau A record) ke dalam file JSON tersebut.
4. Kirimkan Pull Request (PR) untuk ditinjau dan disetujui secara otomatis.
